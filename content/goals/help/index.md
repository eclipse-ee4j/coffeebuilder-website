## help {#help}

The `help` goal is generated by the Maven Plugin Plugin. It displays the plugin's goals and parameter metadata; it does not generate or modify application code.

### Parameters

| Maven property | Type | Required | Default | Meaning |
|---|---|---:|---|---|
| `detail` | `boolean` | No | `false` | Show the full set of goal details. |
| `goal` | `String` | No | — | Limit output to one goal. |
| `indentSize` | `int` | No | `2` | Number of spaces used for each indentation level. |
| `lineLength` | `int` | No | `80` | Maximum display line length. |

### Example

```shell
mvn org.eclipse.coffeebuilder:coffee-builder-maven-plugin:0.1.0-SNAPSHOT:help \
  -Ddetail=true \
  -Dgoal=add-persistence
```

Because `help` describes the locally installed descriptor, it is also a useful way to inspect the exact snapshot present in a developer's Maven repository.
