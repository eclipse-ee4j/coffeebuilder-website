Eclipse Coffee Builder for Jakarta EE™ is developed as an open Eclipse Foundation project. Questions, issue reports, proposals, documentation improvements, and code contributions are welcome.

## Project channels {#project-channels}

- **Official project:** [Eclipse Coffee Builder for Jakarta EE](https://projects.eclipse.org/projects/ee4j.coffeebuilder)
- **Source:** [eclipse-ee4j/coffeebuilder](https://github.com/eclipse-ee4j/coffeebuilder)
- **Issues:** [GitHub issue tracker](https://github.com/eclipse-ee4j/coffeebuilder/issues)
- **Development mailing list:** [coffeebuilder-dev](https://accounts.eclipse.org/mailing-list/coffeebuilder-dev)

The issue tracker is the right place for reproducible bugs, focused feature requests, and concrete work items. Use `coffeebuilder-dev` for broader technical discussion, project direction, and coordination with the project team and community. The mailing list is public and requires an Eclipse account to subscribe.

## Contributing {#contributing}

Before preparing a contribution, read the repository's [contributor guide](https://github.com/eclipse-ee4j/coffeebuilder/blob/develop/CONTRIBUTING.md). It describes the active development branch, build prerequisites, pull-request expectations, Eclipse Contributor Agreement, and sign-off requirements.

All participation in the project is governed by the [Community Code of Conduct](https://github.com/eclipse-ee4j/coffeebuilder/blob/develop/CODE_OF_CONDUCT.md).

Useful starting points:

1. Search the [existing issues](https://github.com/eclipse-ee4j/coffeebuilder/issues) before opening a new one.
2. Keep proposed changes focused and include tests where appropriate.
3. Follow the build and contribution checks documented in `CONTRIBUTING.md`.
4. Use the development mailing list when an idea would benefit from community discussion before implementation.

## Security {#security}

Security vulnerabilities must not be reported through public issues, discussions, or pull requests. Follow the repository's [Security Policy](https://github.com/eclipse-ee4j/coffeebuilder/blob/develop/SECURITY.md), which provides the Eclipse Foundation coordinated-disclosure process and confidential reporting destination.
