Start small. Evolve with purpose.

Eclipse Coffee Builder for Jakarta EE™ helps developers start with a small, understandable Jakarta EE application and evolve it incrementally through focused Maven operations.

Coffee Builder generates the foundation. The developer builds the application.

Development status

Eclipse Coffee Builder is incubating. The current development line is 0.1.0-SNAPSHOT; it is not a stable, published release.

Project principles

Incremental

Add capabilities as the application evolves.

Composable

Use the focused operations that each project needs.

Portable

Keep the application grounded in Jakarta EE and Maven.

Understandable

Make generated code and configuration available to inspect and change.

Developer-owned

Leave architecture and implementation decisions with the development team.

What Coffee Builder is not

  • It does not replace Jakarta EE.
  • It does not hide generated code.
  • It does not impose a complete application architecture.
  • It does not replace developer decisions.

Keep building

Inspect the generated foundation, adapt it to the application, and continue with the Jakarta EE and Maven tools you already use.
